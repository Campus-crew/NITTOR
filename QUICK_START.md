# Быстрый старт - Flow AI Video Generator

## Как использовать приложение

### 1. Главная страница
- Откройте `http://localhost:3000`
- Нажмите **"Создать видео"**

### 2. Создание сценария
На странице редактора вы увидите две вкладки: **Сценарий** и **Видео**.

#### Вкладка "Сценарий"
1. В левой панели (чат) введите тему или описание вашего видео
   - Например: "Видео о путешествии в горы"
   - Или: "Рекламный ролик для кофейни"
2. Нажмите кнопку отправки (или Enter)
3. ИИ создаст структуру сценария с несколькими сценами
4. Вы увидите список сцен с их длительностью и описанием

### 3. Генерация кадров
После создания сценария переключитесь на вкладку **"Видео"**.

#### Выбор режима генерации
В правом верхнем углу выберите режим:
- **Видео по описанию** - генерация по текстовому промпту
- **Видео по картинкам** - загрузка изображений для генерации

#### Режим "Видео по описанию"
1. Выберите сцену из списка справа
2. В чате опишите, как должен выглядеть кадр
   - Например: "Горный пейзаж на рассвете, туман в долине"
3. Нажмите отправить
4. Начнётся генерация (в реальном приложении будет polling статуса)
5. Когда кадр готов, нажмите **"Сцена готова → Следующая"**

#### Режим "Видео по картинкам"
1. Выберите сцену из списка справа
2. Загрузите изображения (макс. 10MB каждое)
3. Опционально добавьте текстовое описание
4. Нажмите отправить
5. Начнётся генерация

#### Сохранение общих черт
- Включите чекбокс **"Сохранять общие черты"**
- Это позволит сохранить стиль, персонажей и другие элементы между кадрами
- Отключите, если хотите полностью новый стиль для следующего кадра

### 4. Работа с таймлайном
Внизу экрана находится таймлайн-редактор с тремя дорожками:
- **Видео** - сгенерированные видео-кадры
- **Аудио** - фоновая музыка или озвучка
- **Текст** - текстовые оверлеи и титры

#### Операции монтажа
- **Вырезать** - удалить часть клипа
- **Вставить** - добавить новый клип
- **Ускорить** - увеличить скорость воспроизведения
- **Замедлить** - уменьшить скорость воспроизведения

Кликните на клип в таймлайне, чтобы выбрать его, затем используйте кнопки операций.

### 5. Плеер
В центре экрана находится видео-плеер:
- **Пробел** или **K** - воспроизведение/пауза
- Прогресс-бар показывает текущую позицию
- Волновая форма внизу показывает аудио

### 6. Экспорт (будет реализовано)
После завершения монтажа:
1. Нажмите кнопку экспорта
2. Выберите качество и формат
3. Скачайте готовое видео

## Горячие клавиши

- **Пробел** - воспроизведение/пауза
- **K** - воспроизведение/пауза (альтернатива)
- **Enter** (в чате) - отправить сообщение
- **Shift + Enter** (в чате) - новая строка

## Текущие ограничения (Mock API)

Сейчас приложение использует mock API для демонстрации:
- Генерация сценария возвращает фиксированный шаблон
- Генерация кадров симулирует задержку, но не создаёт реальное видео
- Статус задач обновляется автоматически через polling
- Загруженные изображения не отправляются на сервер

## Интеграция с реальным бэкендом

Для подключения к вашему бэкенду:
1. Обновите endpoints в `lib/api.ts`
2. Добавьте `.env.local` с URL бэкенда
3. Настройте CORS на бэкенде
4. Обновите типы под ваши API-контракты

Подробнее см. `PROJECT_OVERVIEW.md`

## Troubleshooting

### Приложение не запускается
```bash
# Убедитесь, что установлены зависимости
npm install

# Очистите кэш и пересоберите
rm -rf .next
npm run dev
```

### TypeScript ошибки
```bash
# Проверьте типы
npm run build
```

### Стили не применяются
```bash
# Убедитесь, что Tailwind настроен правильно
# Проверьте tailwind.config.ts и globals.css
```
