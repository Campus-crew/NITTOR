# Настройка API для генерации

## 🎯 Что нужно

Для полноценной работы приложения нужны 2 API:

1. **OpenAI API** - для генерации сценариев (умные описания сцен)
2. **Higgsfield API** - для генерации видео из текста/изображений

## 📝 Шаг 1: Создайте `.env.local`

Скопируйте `.env.example` в `.env.local`:

```bash
cp .env.example .env.local
```

## 🔑 Шаг 2: Получите API ключи

### OpenAI API (для сценариев)

1. Зарегистрируйтесь на https://platform.openai.com/
2. Перейдите в **API keys**: https://platform.openai.com/api-keys
3. Нажмите **Create new secret key**
4. Скопируйте ключ (начинается с `sk-...`)
5. Добавьте в `.env.local`:

```env
OPENAI_API_KEY=sk-ваш-ключ-здесь
```

**Стоимость:** ~$0.01-0.05 за сценарий (модель gpt-4)

### Higgsfield API (для видео)

1. Зарегистрируйтесь на https://higgsfield.ai/
2. Получите API ключ в личном кабинете
3. Добавьте в `.env.local`:

```env
HIGGSFIELD_API_KEY=ваш-ключ-здесь
HIGGSFIELD_API_URL=https://api.higgsfield.ai/v1
```

**Примечание:** Если у Higgsfield другой URL API, обновите `HIGGSFIELD_API_URL`

## 🚀 Шаг 3: Перезапустите сервер

```bash
npm run dev
```

## ✅ Проверка

### Проверить OpenAI

1. Откройте http://localhost:3002/generate
2. Вкладка "Scenario"
3. Введите тему: "Промо видео для нового продукта"
4. Нажмите Send
5. **Если OpenAI работает:** получите детальные сцены с умными описаниями
6. **Если нет:** получите базовые сцены (fallback)

### Проверить Higgsfield

1. Вкладка "Video"
2. Выберите режим "Description"
3. Введите описание или оставьте пустым (будет использован AI prompt из сцены)
4. Нажмите Send
5. **Если Higgsfield работает:** видео будет генерироваться реально
6. **Если нет:** получите демо видео (fallback)

## 🔍 Отладка

### Проверить что ключи загружены

Добавьте в любой API route:

```typescript
console.log("OpenAI configured:", !!process.env.OPENAI_API_KEY);
console.log("Higgsfield configured:", !!process.env.HIGGSFIELD_API_KEY);
```

### Проверить логи

Откройте терминал где запущен `npm run dev` и смотрите логи:

```
Higgsfield job created: job-xxx
```

или

```
Higgsfield API error: ...
```

### Проверить в браузере

Откройте DevTools → Network → найдите запрос `/api/scene/generate`

В ответе должно быть:

```json
{
  "success": true,
  "usingHiggsfield": true,  // ← должно быть true
  "higgsfieldJobId": "..."
}
```

## 🎬 Как это работает

### Генерация сценария

1. Пользователь вводит тему
2. Запрос идёт в `POST /api/scenario/generate`
3. Если `OPENAI_API_KEY` настроен:
   - Вызывается OpenAI GPT-4
   - Генерируется детальный сценарий с промптами для каждой сцены
4. Если нет:
   - Возвращается fallback сценарий (3 базовые сцены)

### Генерация видео

1. Пользователь выбирает сцену и вводит описание
2. Запрос идёт в `POST /api/scene/generate` (FormData)
3. Если загружены изображения - конвертируются в base64
4. Если `HIGGSFIELD_API_KEY` настроен:
   - Вызывается Higgsfield API
   - Создаётся реальная задача генерации
   - Возвращается `higgsfieldJobId`
5. Если нет:
   - Создаётся mock задача
   - Симулируется прогресс
   - Возвращается демо видео

### Отслеживание прогресса

1. Фронтенд опрашивает `GET /api/jobs/{jobId}` каждые 2 секунды
2. Если `HIGGSFIELD_API_KEY` настроен:
   - Проверяется реальный статус в Higgsfield
   - Возвращается прогресс и URL готового видео
3. Если нет:
   - Симулируется прогресс (0% → 10% → 30% → 50% → 100%)
   - Возвращается демо видео URL

## 💡 Рекомендации

### Для разработки

- **Без API ключей:** Всё работает с fallback, можно тестировать UI
- **Только OpenAI:** Умные сценарии, но демо видео
- **Только Higgsfield:** Базовые сценарии, но реальное видео
- **Оба API:** Полный функционал

### Для продакшена

- ✅ Настройте оба API
- ✅ Добавьте обработку ошибок
- ✅ Настройте rate limiting
- ✅ Мониторьте расходы

## 📊 Стоимость

### OpenAI (сценарии)

- **gpt-4:** ~$0.03 за 1K tokens
- **Один сценарий:** ~500-1000 tokens = $0.01-0.03
- **100 сценариев/день:** ~$1-3/день

### Higgsfield (видео)

- Зависит от тарифного плана
- Обычно: $X за минуту видео
- Проверьте на https://higgsfield.ai/pricing
