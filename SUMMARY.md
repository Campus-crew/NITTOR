# Резюме проекта Flow - AI Video Generator

## ✅ Что реализовано

### Страницы
1. **Лендинг (`/`)** 
   - Тёмная тема с жёлтыми акцентами (в стиле Higgsfield)
   - Призыв к действию "Создать видео"
   - Описание возможностей (сценарий, кадры, монтаж)

2. **Редактор (`/generate`)**
   - Трёхпанельный интерфейс:
     - Левая панель: чат для сценария/видео
     - Центральная панель: плеер + таймлайн
     - Правая панель: список сцен (на вкладке "Видео")

## 🎯 Основной workflow

1. **Главная** → Нажать "Создать видео"
2. **Сценарий** → Описать тему → Получить структуру сцен
3. **Видео** → Выбрать режим (описание/картинки)
4. **Генерация** → Для каждой сцены:
   - Выбрать сцену из списка
   - Описать кадр или загрузить изображения
   - Отправить запрос
   - Дождаться генерации
   - Нажать "Сцена готова → Следующая"
5. **Монтаж** → Работа с таймлайном (вырезать, ускорить, и т.д.)
6. **Экспорт** → Скачать готовое видео

## 🔌 Интеграция с бэкендом

### Что нужно изменить:

1. **Обновить endpoints** в `lib/api.ts`:
   ```typescript
   const API_URL = process.env.NEXT_PUBLIC_API_URL || 'http://localhost:3000';
   
   // Заменить /api/* на ваши endpoints
   ```

2. **Добавить `.env.local`**:
   ```
   NEXT_PUBLIC_API_URL=https://your-backend.com
   API_SECRET_KEY=your-secret-key
   ```

3. **Обновить типы** под ваши API-контракты в `lib/api.ts`

4. **Добавить upload для файлов**:
   - Изображения (FormData)
   - Аудио (FormData)

### API контракты (ожидаемые):

См. `PROJECT_OVERVIEW.md` раздел "API Контракты"

## ⚠️ Известные ограничения (Mock API)

- Генерация сценария возвращает фиксированный шаблон
- Генерация кадров не создаёт реальное видео
- Polling симулирует прогресс (20% каждые 2 секунды)
- Загруженные изображения не отправляются на сервер
- Операции таймлайна не применяются к реальному видео
