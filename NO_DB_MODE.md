# Режим работы без базы данных

## ✅ Текущее состояние

Приложение настроено для работы **БЕЗ базы данных**. Все API endpoints используют in-memory хранилище.

## 🎯 Что работает

### ✅ Генерация сценариев
- `POST /api/scenario/generate` - создает сценарий с 3 сценами
- Данные возвращаются клиенту, но не сохраняются в БД

### ✅ Генерация видео
- `POST /api/scene/generate` - принимает FormData с изображениями
- Сохраняет файлы в `public/uploads/`
- Возвращает jobId для отслеживания

### ✅ Отслеживание прогресса
- `GET /api/jobs/{jobId}` - симулирует прогресс генерации
- Использует in-memory Map для хранения статуса
- Через 5-6 запросов возвращает готовое видео (демо URL)

### ✅ Загрузка изображений
- Компонент ImageUpload работает полностью
- Файлы валидируются и отправляются через FormData
- Сервер сохраняет их в файловую систему

## 🚀 Запуск

```bash
npm run dev
```

Откройте http://localhost:3001/generate

## 📝 Workflow

1. **Создание сценария:**
   - Перейдите на вкладку "Scenario"
   - Введите тему видео
   - Нажмите Send
   - Получите 3 сцены

2. **Генерация видео:**
   - Переключитесь на вкладку "Video"
   - Выберите режим (Description или Images)
   - Если Images - загрузите изображения
   - Введите описание
   - Нажмите Send
   - Наблюдайте за прогрессом
   - Через ~10 секунд видео появится в превью

3. **Следующая сцена:**
   - Нажмите "Scene Done → Next"
   - Повторите генерацию для следующей сцены

## ⚠️ Ограничения без БД

- ❌ Проекты не сохраняются
- ❌ Сценарии теряются при перезагрузке
- ❌ История генераций не хранится
- ❌ Нет персистентности между сессиями
- ⚠️ Прогресс задач хранится только в памяти сервера

## 🔧 Включение базы данных

Когда будете готовы использовать PostgreSQL:

### 1. Создайте `.env.local`:
```env
DATABASE_URL="postgresql://user:password@localhost:5432/nittor?schema=public"
```

### 2. Примените схему:
```bash
npm run db:push
```

### 3. Раскомментируйте Prisma код:

В следующих файлах найдите `// TODO: Uncomment when DATABASE_URL is configured` и раскомментируйте код:

- `app/api/scene/generate/route.ts`
- `app/api/scenario/generate/route.ts`
- `app/api/jobs/[id]/route.ts`
- `app/api/projects/route.ts`
- `app/api/projects/[id]/route.ts`

### 4. Перезапустите сервер:
```bash
npm run dev
```

## 🎬 Демо видео

При завершении генерации используется публичное демо видео:
`https://commondatastorage.googleapis.com/gtv-videos-bucket/sample/BigBuckBunny.mp4`

Это позволяет протестировать весь workflow без реальной генерации.

## 📦 Загруженные файлы

Изображения сохраняются в:
```
public/uploads/{uuid}-{filename}
```

Доступны по URL: `/uploads/{uuid}-{filename}`
